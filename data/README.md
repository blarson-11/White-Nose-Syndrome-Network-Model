# Data Sources

## 1. County Adjacency Data

Source: U.S. Census Bureau

Dataset: 2026 County Adjacency File

Download:
https://www2.census.gov/geo/docs/reference/county_adjacency/county_adjacency2026.txt

Format: Pipe-delimited text file.

Contains county GEOIDs, neighboring county GEOIDs,
county names, neighbor names, and shared boundary lengths.

## 2. County Geographic Boundaries

Source: U.S. Census Bureau

Dataset: 2026 TIGER/Line County Shapefile

Download:
https://www2.census.gov/geo/tiger/TIGER2026/COUNTY/tl_2026_us_county.zip

The TIGER file is loaded directly through GeoPandas
and is not stored in this repository.

## 3. Historical WNS Data

Historical WNS surveillance data has not yet been
integrated into the current model.

Initial infection locations are hypothetical
demonstration conditions.
